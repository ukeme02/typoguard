# TypoGuard

Privacy-first browser extension for recovering long-form text after accidental loss.

## Status

Early development.

## Core Principles

- Local-only storage
- No network requests
- No global keyboard capture
- Capture only textarea and contenteditable editors
- Sensitive-field protection
- Explicit user-controlled restoration
- Open source

## Architecture

Manifest V3 + Vanilla JavaScript + chrome.storage.local
